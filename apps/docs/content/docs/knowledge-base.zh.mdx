import { Callout } from "fumadocs-ui/components/callout";

知识库把散落在任务、对话、代码和文档里的团队知识整理成页面。页面由智能体编写和维护，每条事实都附有来源；成员负责阅读、批注和审核，改动经过审核合并后才会生效。

<Callout type="info">
成员不能在界面上直接编辑页面。想改内容，就批注，或者新建一个[知识库作业](#jobs)交给智能体。
</Callout>

## 改动怎么进入知识库 [#flow]

所有改动都走同一条路径：

1. 智能体在一份**草稿**里新增、修改、移动或删除页面；
2. 草稿通过提交前检查后，**提交审核**，生成一个变更请求；
3. 成员审核，维护者**合并**；合并后页面更新，旧版本保留在页面历史里。

草稿没合并前，只有草稿作者和有权限的人能看到，正式页面不受影响。

## 新建知识库 [#create]

在侧边栏打开**知识库**。工作区还没有知识库时，点**新建知识库**；已有知识库时，从左上角的知识库切换器或 **⋯** 菜单新建。

新建页面左边是和**知识库构建器**的对话，右边是配置：

1. 选择构建器使用的运行时和模型；
2. 点一张起始卡片（研发、测试、产品、团队综合、Agent 团队记忆或其他），或直接描述你想要的知识库。构建器会问清读者和用途，并把结果填进右侧；
3. 检查右侧配置，然后点**创建**。

| 配置 | 说明 |
|---|---|
| 名称、简介 | 显示在切换器和首页。 |
| 目录名 | 知识库的 slug，只能用小写字母、数字和连字符，创建后不能修改。 |
| 目标 | 读者是谁、收录什么、不收录什么、典型用途。智能体写页面时会读取。 |
| Schema | 页面怎么组织、怎么写。**默认**使用内置 Schema，只读；**自定义**可以自由编写，新建时默认是自定义且为空。 |

不想要了就点**放弃创建**，对话和配置会一起删除。没完成的创建会保留，下次可以接着做。

创建后，知识库首页会给出上手建议：先收录资料，审核后生效，再阅读和批注，最后设置定时维护。

### 修改配置

在 **⋯** 菜单选择**配置知识库**，可以继续和构建器对话，或直接修改目标和 Schema，点**保存**立即生效。只有知识库创建者和工作区的 `owner`、`admin` 能修改配置。

## 浏览知识库 [#browse]

打开**知识库**会回到你上次看过的那个。左栏从上到下是：

- **知识库切换器**：每个知识库旁显示待处理数量；
- **⋯ 菜单**：新建知识库、配置知识库、知识库管理、审核、变更记录、复制链接；
- **首页**、**知识库作业**、**关系图**；
- **页面**：页面树。

### 首页

首页显示知识库简介和**待处理**的三类事项：

- **待审核修改**：等待审核的变更请求；
- **批注**：还没处理的批注，包括智能体上报的缺口；
- **需要复核的页面**：已经过了复核日期的页面。

下面的**最近更新**列出最近合并的改动。侧边栏的**知识库**入口在有待审核修改时会显示数量，点它直接进入审核。

### 阅读页面

页面正文里的每条事实都带编号引用，悬停查看来源：任务、对话、合并请求、代码、文件或网页。代码来源会显示核对时的版本和行号；对话来源只有发起人能打开。页尾的**引用来源**列出全部来源。

页面顶部有三个面板开关：

- **本页批注**：查看和添加这一页的批注；
- **目录**：页面的标题结构；
- **页面信息**：下次复核日期、领域、引用来源数量，以及哪些页面链接到这一页。

**更多**菜单里有**页面历史**、**让智能体检查本页**和**复制链接**。

页面链接到一个还没写的页面时，会标明这一页还没有写。在页面树某个位置点 **+**，选择**让智能体在这里写一页**，填写要写什么，就会新建一个作业。

如果你有草稿改了当前页面，页面顶部会出现提示，可以在**正式**和**草稿**之间切换，并打开**显示差异**。

### 搜索

- 首页的搜索框只搜当前知识库，结果直接定位到命中的段落；
- 在知识库里任意位置按 <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>F</kbd>（Windows / Linux 为 <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>F</kbd>）搜索全部知识库；
- 在页面里按 <kbd>⌘</kbd> <kbd>F</kbd> 查找本页文字。

默认只按关键词检索。自托管实例同时设置 `MARVIS_EMBEDDING_BASE_URL`、`MARVIS_EMBEDDING_API_KEY` 和 `MARVIS_EMBEDDING_MODEL`，并且 Postgres 装有 pgvector 扩展时，会再加上语义检索。embedding 服务可以是任何兼容 OpenAI `/v1/embeddings`、能返回 1024 维向量的模型。

<Callout type="warning">
开启语义检索后，已合并页面的文字和每次搜索的关键词会发送给 embedding 服务；草稿不会发送。
</Callout>

### 关系图

左栏的**关系图**按页面之间的链接画出整个知识库，颜色区分一级页面。没有任何链接的页面、还没写的页面画成虚线。点节点打开页面。

## 批注 [#annotations]

发现内容有误、缺失或过时，就留一条批注，智能体处理时会看到。批注有三个范围：

| 范围 | 怎么添加 |
|---|---|
| 一句话 | 在页面上选中文字，点**批注**。智能体会看到这句原文。 |
| 一个页面 | 打开**本页批注**，点**添加批注**。 |
| 整个知识库 | 在首页打开**知识库批注**，点**添加批注**。 |

批注的状态：

| 状态 | 含义 |
|---|---|
| **待处理** | 还没有改动处理它。 |
| **处理中** | 有一个变更请求处理了它，等待合并。变更请求被关闭时退回待处理。 |
| **已解决** | 处理它的变更请求已合并。 |
| **不处理** | 决定不改。可以**恢复**为待处理。 |

批注作者、知识库创建者和 `owner`、`admin` 可以把批注标为**不处理**或恢复。

原句被改写后，批注会跟着新句子；原句被删除时，批注会保留当时的原文。

点**交给智能体处理**可以把一条批注交出去；批注面板也可以一次交出全部未处理的批注。两种方式都会新建一个处理批注的作业。

## 知识库作业 [#jobs]

知识库作业是写入知识库的主要方式：你和一个智能体对话，它在草稿里改页面，你检查后提交审核。

在左栏打开**知识库作业**，点**新建作业**：

1. 选择**执行智能体**。只能选你有权使用、运行时可用的智能体；
2. 选一张起始卡片，或者直接描述要做的事：

| 作业 | 做什么 |
|---|---|
| **收录资料** | 把任务、对话、代码、文件或网页里的知识写成页面，智能体会先问你要收录哪些。 |
| **健康检查** | 检查过时、矛盾和缺失的内容，结果记成批注，不直接改页面。 |
| **知识合并** | 合并重复或重叠的页面。 |
| **处理批注** | 按批注修改页面。 |
| **创建定时收录**、**创建定时健康检查** | 让智能体创建一条[自动化](/autopilots)，按时间表运行，之后在自动化页面管理。 |

批注、**让智能体检查本页**、页面树的 **+**、原始资料和复核列表都能直接新建作业，并自动带上对应的内容。

作业页左边是对话，可以随时补充要求或停止；右边是**草稿改动**，列出新增、修改、移动和删除的页面，以及**提交前检查**的结果：

- **错误**必须修好才能提交，例如页头缺少必填字段、事实没有来源、同一层有同名页面、存在未解决的冲突；
- **警告**不阻止提交，例如代码来源缺少版本、链接指向还没写的页面。

可以点**让智能体修复**处理检查问题；主线在此期间有了冲突的改动时，点**让智能体基于主线更新**。

确认无误后点**提交审核**。要等智能体这一轮结束，并且只有草稿创建者能提交；提交后草稿变为只读。不想要这些改动就点**放弃草稿**，作业会保留在列表里。

作业只有发起人能看到和打开。列表可以按运行中、失败筛选。不需要的作业可以归档，归档后才能删除；删除会连同对话一起删掉，并放弃还没提交的草稿。

## 审核和合并 [#review]

在 **⋯** 菜单选择**审核**，或从首页的**待审核修改**、侧边栏数量提示、收件箱进入。变更请求的状态：

| 状态 | 含义 |
|---|---|
| **待审核** | 等待审核。 |
| **待解决** | 审核人提出了意见，等作者处理。 |
| **已合并** | 改动已生效。 |
| **已关闭** | 没有合并就结束了。 |

详情页显示风险等级、影响的页面数、处理的批注数、智能体的自查和变更说明，以及能否合并到主线；下方是每个页面的改动对比和动态。

### 提出审核意见

1. 点**开启评审**；
2. 在改动里选中行，点**加入评审**写意见。提交前只有你能看到；
3. 点**提交评审**，可以附一段总结。变更请求变为**待解决**，作者会收到通知。

作者可以在作业页点**交给智能体处理**，让智能体在同一份草稿里修改并逐条回复，然后**重新请求审核**，变更请求回到待审核。不是维护者的成员不能评审自己提交的变更请求。

### 合并、关闭和回滚

- **合并**：只有知识库创建者和 `owner`、`admin` 可以合并。有冲突、有检查错误、智能体正在修改或状态为待解决时不能合并。页面在此期间被别人改过时，Marvis 按段落合并，只有同一段两边都改了才算冲突。
- **关闭**：作者和维护者可以关闭，可以填写理由。关闭的变更请求可以在作业页**重新提交审核**。
- **回滚**：维护者可以在已合并的变更请求、**变更记录**或页面历史里点**回滚此次变更**。回滚针对整个变更请求，会生成一个反向的变更请求，合并后才生效。之后的改动动了同样内容时无法自动回滚。

**变更记录**列出所有已合并的改动；页面的**页面历史**列出这一页的每个版本，点开查看改动。

## 需要复核的页面 [#stale]

每个页面都有复核日期，过期后出现在首页的**需要复核的页面**里，并在页面树和正文中标出。复核列表可以把单个页面**交给智能体复核**，也可以全部交出，都会新建作业。

## 通知 [#notifications]

收件箱的**知识库**分类收集知识库通知：

- 有新的变更请求或回滚等待审核，或者作者重新请求审核时，通知维护者或审核人；
- 审核人提交评审意见后，通知作者。

变更请求合并或关闭后，相关的旧通知会自动归档。

## 在任务和对话里使用知识库 [#agents]

执行任务、聊天和自动化时，智能体会知道工作区里有哪些知识库，可以搜索和读取页面，也可以提交草稿和变更请求；变更请求会标明来自哪个任务、对话或自动化。智能体通过 `marvis kb` 命令读写知识库，权限与成员在界面上的权限相同。

智能体在回复里引用知识库、页面、变更请求或批注时，会显示为可点击的卡片。点击只会打开对应内容，不会通知任何人。

## 管理知识库 [#manage]

在 **⋯** 菜单选择**知识库管理**：

- **原始资料**：上传文件供智能体收录，单个文件不超过 100 MB。选中文件后点**交给智能体收录**会新建收录作业；列表显示每个文件被哪些页面引用。
- **导出**：点**导出 zip**，每个页面导出为带 frontmatter 的 Markdown 文件，页面之间的链接改成相对路径，可以直接用 Obsidian 等工具打开。
- **删除知识库**：输入知识库名称确认后删除。删除会关闭它的批注和待审核修改，界面上无法恢复。

## 权限 [#permissions]

知识库的**维护者**是知识库创建者和工作区的 `owner`、`admin`。

| 操作 | 谁可以 |
|---|---|
| 阅读、搜索、批注、导出、上传原始资料、新建作业、评审 | 所有成员；新建作业还需要有权使用所选智能体 |
| 修改配置、合并、回滚、删除知识库 | 维护者 |
| 关闭变更请求，把批注标为不处理或恢复 | 作者或维护者 |
| 提交草稿、重新请求审核 | 草稿创建者 |
| 查看作业 | 作业发起人 |
