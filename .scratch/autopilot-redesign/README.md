## 结论速览

- 列表：表格改两列卡片（标题、两行指令摘要、元信息行），「新建自动化」下拉含模板，去掉多选与批量。
- 详情：左配置、右指令与运行记录，编辑 / 删除 / 立即运行在顶栏。
- 运行对话（仅运行）：第一轮仍是自动化任务，第二轮起走聊天；一次运行一个对话，能查看该自动化的成员共用；运行中发的消息排队，运行结束后接着运行的会话继续。「创建任务」模式不变，运行记录跳任务详情。
