# 05: 运行中发消息排队

**What to build:** 运行还在进行时，成员也能在运行详情页发消息（设计稿 3.2、3.3）：消息进对话队列，显示为排队中，等运行结束才派给智能体，接着运行的会话继续（决策 12、15）。

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 获取或创建对话接口允许运行中创建（运行任务未结束时不预填指针）
- [x] 运行任务结束（完成或失败）时，若这次运行已有对话，把任务的会话 ID / 工作目录 / 运行时写进对话指针
- [x] 认领条件加一条：聊天任务所属对话挂在某次运行上、且该运行的任务未结束时不认领；运行任务本身不挂对话，提示词与归属不变
- [x] 前端运行中输入框可用，按钮「停止」/「排队发送」与聊天页一致
- [x] 测试：运行中发的消息在运行结束前不被认领、结束后被认领且续接到运行的会话
