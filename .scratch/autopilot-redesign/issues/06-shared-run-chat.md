# 06: 运行对话多人共用

**What to build:** 一次运行一个对话，能查看这个自动化的成员都能看到、都能发消息；每条用户消息显示发送人（设计稿 3.4，右侧「能查看这个自动化的成员共用这段对话。」）。这些对话不出现在「我的对话」列表；删除自动化时一并清理（决策 10、15）。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 会话访问：挂在运行上的会话按「能查看该自动化」放行，其余聊天仍只给创建者；每次发送仍按发送人检查能否调用智能体，追问任务归属发送人
- [ ] 发送人不加列：消息列表按消息对应任务返回发起人 `sender_user_id`（可空）；core schema 加可选字段；运行页用户消息显示头像和名字，缺省回退会话创建者
- [ ] 聊天列表（及相关未读 / 浮动入口统计）排除挂在运行上的会话
- [ ] 删除自动化时归档关联会话
- [ ] 测试：第二个成员能读写同一运行对话；无该自动化权限的成员 404；聊天列表不含这类会话
