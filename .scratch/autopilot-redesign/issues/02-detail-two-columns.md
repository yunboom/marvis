# 02: 自动化详情改成两栏

**What to build:** 自动化详情页是两栏（设计稿 2.1–2.4）：左栏配置（状态开关 + 下次运行、执行者 / 创建者 / 输出方式 / 项目、订阅者（仅创建任务模式）、触发器、Webhook 投递），右栏指令（默认折叠、可展开）与运行记录。顶栏是返回 + 两行标题，编辑 / 删除为图标按钮，立即运行为主按钮。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 启停开关从标题旁移到左栏「状态」，显示下次运行；归档时禁用照旧
- [ ] 运行时缺失横幅 + 绑定运行时链接照旧
- [ ] 触发器：添加、编辑时间表、删除、Webhook 地址复制 / 重置、已停用 / 已弃用标记，行为不变，只换样式
- [ ] 指令默认折叠约 5 行，可展开 / 收起；无指令时不显示
- [ ] 运行记录：每行状态图标 + 时间 + 摘要 + 来源；跳过的运行仍折叠成一组；本票内点击行为不变（仍是日志弹窗 / 跳任务）
- [ ] 页面底部危险区去掉，删除移到顶栏图标，确认框照旧
- [ ] 只读用户不显示编辑、删除、立即运行、触发器增删改
- [ ] 窄屏两栏堆叠
- [ ] `pnpm typecheck`、`pnpm lint`、相关 `pnpm test` 通过
