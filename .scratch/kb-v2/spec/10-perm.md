# 10 权限

| 操作 | 成员 | 知识库创建者 | owner / admin | 说明 | 
| 阅读、检索、批注、导出 | ✓ | ✓ | ✓ |  | 
| 新建知识库作业 | ✓ | ✓ | ✓ | 还要有执行智能体的使用权限 | 
| 看 / 写草稿 | 自己的 | 同左 | 同左 | 作业的草稿属于发起人；作业对话里的任务令牌也能写（决策 22） | 
| 把草稿关联到作业 | 作业发起人 | 同左 | 同左 | 作业里执行的智能体按任务令牌也能关联；草稿须属于同一个知识库且是 open（决策 104） | 
| 新建知识库 | ✓ | — | ✓ |  | 
| 配置（名称、目标、Schema） | — | ✓ | ✓ | 保存即生效 | 
| 合并、回滚 | — | ✓ | ✓ | 人或其智能体，按令牌绑定的人判（决策 30、102） | 
| 关闭变更请求 | 作者 | ✓ | ✓ | 作者能关闭自己的（决策 102） | 
| 上传原始资料 | ✓ | ✓ | ✓ | 和在任务、对话里上传附件一样；资料只是收录的素材，写进页面仍要走变更请求（决策 101） | 
| 删除知识库 | — | ✓ | ✓ | 决策 102 | 
| 读对话（收录用） | 自己发起的 | 同左 | owner：人亲自调用或用自己的私有智能体时可读全员；admin 同成员 | 见 8.7（决策 83） |
